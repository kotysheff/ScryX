# Технические решения ScryX

## 2026-11-06 — рабочий реестр требований

Для разработки используем [реестр требований](requirements/REQUIREMENTS_BASELINE.md). [Паспорт](thesis_passport.md) сохраняет исходные решения и цели. Спорные пункты реестра остаются открытыми до согласования.

## 2026-11-06 — проверка окружения

`pyproject.toml` задаёт конфигурацию проекта. Кандидат для проверки — Python 3.13, PySide6 6.8.x, NumPy 2.3.x и OpenImageIO с проверкой фактической нативной версии OpenEXR. Версии и lock-файл фиксируем после прогона тестов и эталона EXR в чистом окружении. НФТ-15, НФТ-17, НФТ-21 и ИСП-13 остаются открытыми для проверки.
