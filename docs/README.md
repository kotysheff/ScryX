# 📚 Документация и база знаний ScryX

Здесь собраны все материалы по проектированию, тестированию и исследовательской работе вокруг проекта **ScryX** - от опросов пользователей и тестовых оракулов до инженерных заметок и конспектов по компьютерной графике.

## 🛠 Ключевые артефакты проекта

Быстрый доступ к документам по разработке и тестированию:

* [**Пользовательское исследование** (`user_research.md`)](./user_research.md) - исследование болей 3D/VFX-художников: проблемы существующих просмотрщиков (DJV, RV), запоздалое обнаружение битых кадров после рендера, сложности с цветовыми профилями и другое.

* [**Сравнение аналогов** (`competitor_analysis.md`)](./competitor_analysis.md) - эталонные данные первого кадра рендера для верификации парсера OpenImageIO.
* [**Журнал разработки** (`project_journal.md`)](./project_journal.md) - хронология процесса, фиксация архитектурных развилок и принятых решений.
* [**Лабораторные / Спайки** (`labs/01_script_output.md`)](./labs/01_script_output.md) - результаты экспериментов и запусков скриптов из папки `spikes/`.
