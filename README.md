# ScryX

Desktop viewer for CG/VFX image sequences with automated render QC. Fast EXR/PNG/TIFF playback, AOV inspection, and per-frame defect detection — missing frames, NaN pixels, flicker, alpha issues. Diploma project.

**Version:** 0.0.2
**Status:** Prototype, exploratory spike
